### 注册
```bash
/msg NickServ REGISTER passwd xxx@gmail.com
```
接着服务器会发回来验证码到你的邮箱上,将信息在irc上输出验证,注册成功!
```bash
/msg NickServ VERIFY REGISTER adlternative awekqmudxgrr
```
